# RE2 — EX Files (N64) · referencia de diseño

Capturas de los archivos exclusivos de la versión N64 de Resident Evil 2,
descargadas de evilresource.com **solo como referencia de estética** para el
visor del diario (flechas verdes, título arriba, papel arrugado).

> ⚠️ Son assets de Capcom. Esta carpeta NO está en `public/`, así que el build
> del sitio no las publica. No subas los escaneos tal cual a un sitio público;
> úsalas para inspirarte / extraer paleta y texturas.

Descargadas: 2026-06-04
Fuente: https://www.evilresource.com/resident-evil-2/files#exfiles
